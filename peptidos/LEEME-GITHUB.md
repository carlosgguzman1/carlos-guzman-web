# Guía educativa de péptidos · v2.3.0

El proyecto está en la carpeta `peptidos` de este repositorio. Los archivos anteriores del sitio principal se conservan.

Para conectar el proyecto de Vercel `carlos-guzman-peptides` con este repositorio, configura **Root Directory: peptidos**, **Framework: Other**, **Build Command: npm run build**, **Output Directory: dist**. Publica la rama main. Requiere autorizar el acceso de la integración al equipo de Vercel.

El sitio claro ya está disponible en https://carlos-guzman-peptidos.carlitosgeral03.chatgpt.site/ . Esta URL no confirma un despliegue en Vercel.

El workflow opcional dentro de peptidos/.github solo sirve al copiar el proyecto a la raíz de un repositorio independiente; no está activado en este repositorio. No se ha modificado la configuración de GitHub Pages del sitio principal.

Las pruebas cubren las 152 fichas y comparaciones, los ocho sistemas y la prevención de valores vacíos visibles. La revisión clínica integral sigue pendiente.
